# Model authoring

The same composition routine serves chat, saved models, reports, candidate batches and paired
simulators. AGENTS.md owns authorization; INDEX.md routes the task. Read this contract and
the requested dialect's rules once. Reuse supplied code and already loaded examples.

## Compose and deliver

1. Establish the requested structure, route, endpoints/error scale and authorized effects.
   Use an existing base as the source of truth; preserve its structure/starts except for a named
   necessary adaptation. New models are covariate-free with diagonal OMEGA unless requested
   otherwise; preserve supplied terms, approved allometry and retained final effects. Use house
   defaults for routine unspecified choices. Reports reuse their existing intake facts.
2. Make one targeted filename glob in the required dialect and read the closest full skeleton.
   A second example may supply a specific missing feature. Chat/saved code allows TWO examples
   total; paired CTL/CPP uses one per dialect. Reports allow two per required dialect, reused
   across same-structure files/candidates. One continuation read may finish a truncated example.
   A bare continue, rename, save or edit does not renew the budget; a genuinely new model request
   does. No exact-match hunt, corpus grep, third example, policy reread or engine inspection.
   Missing scientific facts need a precise question, never additional template exploration.
3. Compose complete code immediately, applying syntax, units, scale, starts and mappings while
   writing. No reasoning essay, alternatives, speculative review, checklist/lint script or
   read-back cycle. Preserve skeleton record/block order, banners, spacing, names, equations,
   compartment roles and THETA/ETA/EPS order. Extend missing features minimally.
   Use short comments for parameter names, units, section labels and tool markers.
4. Chat delivery starts/ends with the complete ctl/cpp fence, without surrounding prose. No
   authored files, temporary folders, notes, helpers or backups; a data/study path is not a
   save request. An explicit file request uses its destination. Reports save stage-required
   files in the study and continue; writing a model does not complete a report task.

Code-only PKPD/TMDD/turnover/multi-endpoint requests do not enable word-report/,
analyses_template/, analyses_template/tools/ or fitting/report contracts, NCA, fitting, diagrams or validation.
Explicit reviews, maintenance, diagrams and analyses follow their own route. For short code/
figure work, deliver once ready: no compress/decompress/search_context/acp_status housekeeping
without an actual pressure/overflow warning or explicit user request; never invent reference ids.

## Preserve the scientific contract

- Adapt only data path/positional INPUT, requested structure/route/endpoint/error form,
  authorized/retained effects and required starts/fitted values. Preserve unused INPUT/DROP
  fields. If an example has unrequested covariates, use its structural skeleton and assign
  base THETAs directly from the outset; never draft then strip/rewrite covariate effects.
- Supplied/verified fitted starts override example defaults. NCA initials belong only to the
  authorized new-model analysis route. R imports the authored code, never a hardcoded fitting
  substitute. Do not refit for formatting or new simulators.
- Preserve original data, filenames, units, column order, events and response scale; no silent
  rename, duplication, transformation or replacement. A derived dataset needs a user request.
  Without data, mark DATA/INPUT placeholders in short code comments. Do not guess ambiguous
  units/endpoints/scale or invent data; state the necessary limitation/question.
- Turnover stimulation multiplies the intended kin/kout rate by (1+EFF); inhibition by
  (1-EFF). PD KOUT is not PK CL/V. Amount-state derivatives are mass/time. VMAX*C/(KM+C)
  already has mass/time when VMAX does; only a concentration/time VMAX needs volume. KM shares
  concentration units. Preserve shared parent/metabolite RATE_FORM flux and justified molar
  yield FMOL; TMDD receptor/complex states use concentrations.
- For steady-state turnover, estimate R0 and KOUT. Set KIN = R0 * KOUT and initialize
  the response at R0 in both dialects. Match non-steady-state initialization to the study.
  Use the observed baseline and recovery rate as starting values.
- A fraction with IIV uses a readable 0-1 typical parameter, additive ETA on its logit and
  inverse-logit transformation. Without IIV it needs no logit. Never treat a logit start as
  a fraction. Endpoint/error and simulator scales must match the selected response column.
  Multi-DV defaults use log-transformed DV unless natural scale is requested; never pair log
  prediction with raw DV or transform data to satisfy an example. Use native selectors/study
  settings, not toolkit-only CTL annotations.

## Fixed parameters

Estimate parameters unless the human approved the exact name=value. FIX, equal bounds and
literal fitted-parameter assignments all count; copied constants or agent identifiability
arguments are not approval. Distinguish structural flags/baselines, covariate references and
priors from fitted parameters. PMX_FIXED is disclosure only; only human-approved entries enter
PMX_FIXED_APPROVED. No self-approval, retired blanket switch, FIX rescue or comparison of
pinned/estimated variants as equivalent. Record approvals in base_selection.dcf for a screen.

## Report models and authorized artifacts

Read only the input/endpoint/simulator contract needed at the current stage; read Rmd/prose/
layout rules at rendering, not before drafting. Use supplied code first. SCM needs CTL, not CPP;
S2 reuses/translates the frozen model and names any unsupported paired export to author before
--from=s2. Do not add structures/candidates or pre-author simulators for SCM. Use normal wrapper
preflight once and repair only its named defect under existing limits, without redesign,
ledger reset or successful-fit replay. PMX_CODE_READY/PMX_MODEL_READY mean draft/save and advance.
Never replace an authorized report with a chat-only answer.

New authorized files must be share-readable and directories traversable (Linux chmod a+r/a+rx
within the output scope); the ladder chmod backstop is not a substitute. Permission repair
does not authorize source writes. Requested diagrams follow references/rules_deliverables.md.
